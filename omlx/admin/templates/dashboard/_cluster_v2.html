Set up this Mac first

This Mac hasn't introduced itself to the network yet. oMLX does that by itself once distributed inference is on — then a second Mac is all you add.

  1. 1 Open Settings → Advanced and enable Distributed Inference, then restart oMLX.
  2. 2 On your other Mac, install oMLX with one line:
brew install jundot/omlx/omlx

Or download the app from Releases and drag it to Applications — same result. Once both Macs run oMLX, they find each other here automatically.
