# Fase L2 — regime pins: evidence and decision (2026-08-31)

Protocol: single-request 2k decode-48, budget=0, --gate-tokens 48/48, shared
box (loadavg 2-5), --min-free-gb 16. Arms interleaved in one window where the
comparison demands it.

## Profiles (v2, regime-split)
- decode: fasel/l2/profiles/decode.json — learned from a 2k decode-200 run
  (collect_decode.json): 48 layers, decode regime top experts 426/470/384,
  prefill regime top 349/160/32 — regimes are meaningfully disjoint.
- prefill: fasel/l2/profiles/prefill.json — learned from an 8k decode-48 run.
- v1 model profile backed up unmodified: model_v1_backup.json (264 KB).
- Fingerprint: {model, config_sha, source_packing oQ4e4b-gs64, hot_fraction,
  profile_format 2}; arms all report profile_fingerprint_match=true.
- Pinning cost: 432 experts (256 MiB) took 9-25 ms at load (PIN_SYNC).

- decode delta -6.7%; p95 demand +9.8% (wrong direction), p50 +8.0%.
- Native demand reads are already page-cache hits (~2 ms p50); the decode
  working set fits the page cache on this NVMe, so mlock adds wired memory
  without moving the p50/p95.

## Decision (plan acceptance gates)
- decode >=5%: not met (all arms within drift).
- p95 demand -10%: not met (rose ~10%).
- 'If 256-512 MiB does not pay, do not raise the budget automatically: close
  for this model/SSD.' -> pins stay opt-in per model (default OFF), the
  learned-profile machinery (v2 regime split, fingerprint gating, page
  dedupe) is retained as the diagnostic/opt-in path and feeds HOBBIT.
- The 1.25 GiB sizing point also shows no pay; LRU remains closed (L3).
